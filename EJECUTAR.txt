MVP HOSPITAL — SEGUNDO PARCIAL

1) Abre esta carpeta en Visual Studio Code.
2) Ejecuta: python app.py (en Windows, INICIAR.bat).
3) Abre la dirección local mostrada en la terminal.
4) Para iniciar sesión utiliza: admin / doctora / paciente / recepcion / consulta,
   todas con contraseña Demo2026!.
5) Revisa docs/guion_laboratorio.md para ensayar los cinco perfiles.
6) Ejecuta pruebas con: python -m unittest discover -s tests -v

Nota: el sistema requiere el servidor Python; abrir mvp.html como archivo no funciona.
